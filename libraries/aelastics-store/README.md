# @aelastics/store

MobX-based reactive store built on top of `@aelastics/types`: objects
created through the store are tagged with their runtime type, and
assignments to entity-typed properties are validated against the
declared schemas. It is the state layer underneath the Synthesis
model store.

Documented in the
[store section](https://AelasticS.github.io/aelastics/store/intro) of
the docs site.
