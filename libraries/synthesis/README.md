# @aelastics/synthesis

The Synthesis transformation library: the JSX runtime for authoring
models as templates, the metamodel core, the model store integration,
the model-to-model and model-to-text engines, and configuration-based
variability (decision, binding, and configuration models). Metamodel
packages, transformation packages, and the `synth` CLI are all built
on this library.

How to define metamodels, build models with JSX, and write
transformations is documented in the
[developer guide](https://AelasticS.github.io/aelastics/developer-guide).
