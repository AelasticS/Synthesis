# @aelastics/types

Runtime type system for TypeScript: schemas of simple, object, and
collection types with constraints, validation, serialization, and
static type inference, plus graph transducers for traversing and
transforming typed object graphs. It is the foundation the Synthesis
metamodel core builds on.

Documented in the
[types section](https://AelasticS.github.io/aelastics/types/intro) of
the docs site.
