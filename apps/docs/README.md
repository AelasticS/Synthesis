# @synthesis/docs

The Docusaurus documentation site, published at
[AelasticS.github.io/aelastics](https://AelasticS.github.io/aelastics/).

The content lives under `docs/` (user guide, developer guide, and the
types, store, and result sections), the navigation in `sidebars.ts`,
and the site configuration in `docusaurus.config.ts`; the API
reference pages are generated by typedoc at build time.

Run it locally with the package's own scripts (via `rushx` or
`npm run`):

```bash
rushx start    # dev server with live reload
rushx build    # production build into build/
rushx serve    # serve the production build
rushx clear    # clear Docusaurus caches
```
