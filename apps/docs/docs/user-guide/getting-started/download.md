# Download

The `synth` CLI ships as a self-contained bundle per platform. Each bundle
includes Node.js and all dependencies; nothing else needs to be installed
on your machine. It also contains all
[example transformations](../../developer-guide/examples/index.md) with
their sample models, ready to install.

**Current version: v0.4.0.** Release notes for every version are in the
[changelog](https://github.com/AelasticS/Synthesis/blob/main/CHANGELOG.md),
and the
[releases page](https://github.com/AelasticS/Synthesis/releases) lists all
versions with their bundles.

| Platform | Architecture | Download |
|---|---|---|
| Linux | x64 | [synth-v0.4.0-linux-x64.tar.gz](https://github.com/AelasticS/Synthesis/releases/download/cli-v0.4.0/synth-v0.4.0-linux-x64.tar.gz) |
| Linux | arm64 | [synth-v0.4.0-linux-arm64.tar.gz](https://github.com/AelasticS/Synthesis/releases/download/cli-v0.4.0/synth-v0.4.0-linux-arm64.tar.gz) |
| macOS | Intel (x64) | [synth-v0.4.0-darwin-x64.tar.gz](https://github.com/AelasticS/Synthesis/releases/download/cli-v0.4.0/synth-v0.4.0-darwin-x64.tar.gz) |
| macOS | Apple Silicon (arm64) | [synth-v0.4.0-darwin-arm64.tar.gz](https://github.com/AelasticS/Synthesis/releases/download/cli-v0.4.0/synth-v0.4.0-darwin-arm64.tar.gz) |
| Windows | x64 | [synth-v0.4.0-win32-x64.tar.gz](https://github.com/AelasticS/Synthesis/releases/download/cli-v0.4.0/synth-v0.4.0-win32-x64.tar.gz) |

After downloading, continue with [Installation](./installation.md): extract
the archive and add `synth/bin` to your `PATH`.
