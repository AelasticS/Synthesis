# User Guide

This guide is for **users of the `synth` CLI**: you install transformations
that others have published, import your models into a local workspace, and
run transformations, as single steps, chains, or saved pipelines, to
generate new models and code. No knowledge of the Synthesis libraries or of
transformation authoring is required.

If you want to *build* transformations (define metamodels, write
transformation rules, package and publish them), switch to the
[Developer Guide](../developer-guide/index.md).

## How this guide is organized

1. [Installation](./getting-started/installation.md): get the `synth` binary
   onto your machine.
2. [Quick Start](./getting-started/quick-start.md): from an empty workspace to
   generated SQL in a dozen commands.
3. [Concepts](./concepts.md): the workspace, models and refs, transformations,
   pipelines, and the explicit-consent policy for design decisions.
4. [Tutorial](./tutorial.md): a guided end-to-end session with explanations at
   every step.
5. Guides: task-oriented pages on
   [managing models](./guides/managing-models.md),
   [configurations](./guides/configurations.md), and
   [pipelines](./guides/pipelines.md).
6. [Command Reference](./reference/commands.md): every command, flag, and exit
   code.
