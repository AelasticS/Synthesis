# Synthesis

Synthesis is a TypeScript monorepo providing a toolkit for model-driven software engineering.

## Foundations

| Section | Description |
|---|---|
| [Synthesis eDSL](./synthesis/) | Developer guide for writing model-driven transformations in TypeScript with JSX |

## Packages

| Package | Description |
|---|---|
| [synth CLI](./cli/intro) | Command-line tool for running transformations and generating code |
| [@aelastics/result](./result/intro) | Typed success/failure result handling without exceptions |
| [@aelastics/types](./types/intro) | Runtime type system with validation and transformation support |
| [@aelastics/store](./store/intro) | Reactive model store built on MobX |
